Open-source security scanner for MCP servers

Find the hidden instructions in your AI tools.

mcpscan checks every tool's name, description and schema for attacks aimed at your AI assistant, then measures its own accuracy against a labeled test set.

AI assistants trust text nobody checks

        
The Model Context Protocol connects AI assistants to outside tools. Each tool ships a description the assistant reads as instructions, and nothing sanitizes it. A malicious server can hide commands there, and the user never sees them.

      

      

        
Tool poisoning
A weather tool's description tells the assistant to read an SSH key and keep quiet about it.

        
Hidden text
Invisible characters and encoded comments carry instructions a person reviewing the tool never sees.

        
Over-permission
A forecast tool asks for a file path it has no reason to need, the same least-privilege failure seen in cloud access control.

      

      
Scanners for this exist, but false alarms make people stop running them. One published audit of 33 MCP servers found only 6 of 27 detections were genuine. So our headline is a measured accuracy score with every false alarm explained.

    

  


  

    

      
How mcpscan works

      
    
        
  1. ConnectStart a server or load saved tool data, and read every tool it offers. Public servers are only listed, never called.
    2. 
        
  2. AnalyzeSix rules check for instructions aimed at the model, hidden text, lookalike names, credential requests and excess permissions.
    3. 
        
  3. ScoreEach finding gets a severity from everything found on that tool, and quotes the exact evidence.
    4. 
        
  4. MeasureFindings are compared with labeled test servers to produce precision and recall, including clean decoys built to cause false alarms.

    Get started
    
        
    mcpscan needs Python 3.11 or newer.
    
      
    
      
    
        
    
          
    Install
    
          
    git clone https://github.com/rithikagantla/mcp-scanner
cd mcp-scanner
python -m venv .venv
source .venv/bin/activate
pip install .
    
        
    
        
    
          
    Scan
    
          
    # Scan a server
mcpscan scan -- python corpus/servers/01_hidden_instructions/server.py

# Scan saved tool data
mcpscan scan --file samples/filesystem.tools.json

# Block a build on high-severity findings
mcpscan scan --format sarif -o out.sarif --fail-on high -- python server.py

# Run the benchmark
mcpscan bench corpus/

mcpscan Security scanner and benchmark for MCP servers · GDSC ML-1 GitHub repo

AI assistants treat a tool's description as instructions, and nothing sanitizes it. mcpscan reads those descriptions and schemas, flags what looks wrong, and is scored against a test set where we know the right answers.

# results/

Generated by `mcpscan bench corpus/`.

- `results.json`: machine-readable metrics, regenerated each run
- `baseline.json`: last accepted metrics. `tests/test_bench.py` fails if precision or recall drops
  below it. Update it on purpose when a change is reviewed
- `report.md`: the results report. The bench command rewrites only the section between the
  GENERATED markers; the analysis around it is written by hand, so re-read it when numbers change
